# AGENTS.md — Правила для AI-агентов и разработчиков

Этот проект создан как высокоскоростной шаблон для двухчасового MVP-спринта. Любой агент или разработчик, работающий с репозиторием, ОБЯЗАН строго следовать данным правилам:

## 1. Стек и команды запуска
- **Backend:** FastAPI + Pydantic (Python 3.12+)
  - Запуск: `cd backend && .venv/Scripts/uvicorn main:app --reload --port 8000` (Windows) или `uvicorn main:app --reload --port 8000` (Unix с активным `.venv`)
- **Frontend:** React + TypeScript + Tailwind CSS + Vite
  - Запуск: `cd frontend && npm run dev`
- **Запуск всего проекта из корня:**
  - `npm run dev` (одновременный запуск frontend и backend через `concurrently`)

## 2. Жесткое разделение зон ответственности
- Задачи по бэкенду меняют **ТОЛЬКО** файлы в директории `/backend`.
- Задачи по фронтенду меняют **ТОЛЬКО** файлы в директории `/frontend`.
- Запрещено смешивать логику, переносить бэкенд-код во фронтенд или плодить сквозные изменения без необходимости.

## 3. Единый источник правды: API_CONTRACT.md
- Все форматы запросов, эндпоинты, параметры и структуры ответов **строго соответствуют** `API_CONTRACT.md`.
- **Запрещено** молча менять сигнатуры API, имена полей или схемы данных. Любое изменение API сначала фиксируется в `API_CONTRACT.md`, и только затем имплементируется в бэкенде и фронтенде.

## 4. Скорость важнее идеала (Pragmatic MVP)
- **НЕ** пиши юнит-тесты, сложные абстракции и архитектуру «на вырост».
- Приоритет — рабочий вертикальный срез для демонстрации сценария (Happy Path).
- Не усложняй код избыточными слоями абстракций, фабриками и микросервисами.

## 5. Минимализм зависимостей
- **НЕ** устанавливай тяжелые библиотеки (ORM, Celery, Redux, тяжелые UI-киты) без явного запроса пользователя.
- Используй встроенные средства FastAPI/Pydantic и React (`useState`, `useEffect`, `fetch`).

## 6. UI-правила и дизайн-система
- **Тема:** Строгий минимализм, темная тема (`#0B0D10` для фона).
- **Типографика и отступы:** Четкая иерархия, аккуратные консистентные паддинги.
- **Цветовая палитра:** Один сдержанный акцентный цвет (синий/индиго), никаких кислотных градиентов и визуального мусора.
- **Состояния:** Обязательны состояния `loading` и `error` для всех асинхронных операций.
- **Никакого «нейро-дизайна»:** Никаких кислотных градиентов, радужных неоновых свечений, декоративного визуального шума и лишних эмодзи.
